# CSM Fight Karo Lite

**Friends by day. Enemies in the arena.** Pick your CSM Gang fighter and take on the Opposite Gang in a quick, neon-styled campus arcade brawl.

## Play

Choose **Play Now**, select a mode, then pick your fighter. Player 1 can choose only from the CSM Gang roster; Player 2 or the CPU can choose only from the Opposite Gang roster. The game offers same-keyboard local 1v1, solo versus AI (Easy, Normal or Hard), and Practice against a stationary opponent. Matches are best of three rounds with a 60-second timer per round. Win two rounds to take the match; pause, restart or rematch from the game flow.

### Keyboard controls

| Action | Player 1 | Player 2 |
| --- | --- | --- |
| Move | A / D | Left / Right |
| Jump | W | Up |
| Punch | F | K |
| Kick | G | L |
| Block | S | Down |
| Signature special | H | Semicolon (`;`) |

Special attacks require a full energy meter. Successful attacks build energy. On touch devices, use the on-screen movement, jump, punch, kick, block and special buttons.

### Fighters

**CSM Gang:** CR — Chairman's Order; Lady Don — Don's Fury; Shiva Fighter — Shiva Strike; 51 — Fifty-One Blast; 52 — Fifty-Two Smash; 53 — Fifty-Three Explosion; 2nd CR — Second Command; Arabian Horse — Arabian Charge.

**Opposite Gang:** Swapna Taker — Dream Breaker; COA — Architecture Attack; Chubby Cheeks — Cheek Blast; Cheshma Girl — Laser Vision.

## Session-only privacy

This is a browser-only, local game. It has no account, backend, database, Supabase integration or online matchmaking. Match state, results, settings, custom dialogue, voice clips and uploaded face-card photos live only in the current page session. Uploaded personal images and recordings are not sent to a server and are not written to persistent browser storage; closing or reloading the page clears them.

## Run and export

Open `project.godot` in Godot **4.7.2** and run the main scene. The configured **Web** export preset uses `web/loading.html` and targets a browser build. No server or database configuration is needed for gameplay.
